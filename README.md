# 🐍 PyOJ —— Python 刷题平台

一个可以真正跑起来的本地刷题网站，包含打卡、错题本、收藏、限时测验、等级、认证证书、
好友组队、能量菜园、学习圈，以及吉祥物「苗小序」AI 助教。

---

## 一、怎么启动

**方式 1（推荐）：双击项目根目录的 `run.bat`**

**方式 2：命令行**
```bash
cd D:\python_oj
.\ven\Scripts\python.exe run.py
```

启动后会打印地址，例如 `http://127.0.0.1:8000`，用浏览器打开即可。
（如果 8000 端口被别的程序占用，脚本会自动改用 8001、8002……以实际打印为准）

关闭服务：在运行窗口按 `Ctrl + C`。

### 经验规则
- 首次通过一道题 **+30**
- 再次通过已解过的题 **+5**
- 每日打卡 **+10**
- 测验 / 认证达标 **+50**

### ⚡ 能量规则（菜园用的"积分"）
| 获得 | 数量 | 消耗 | 数量 |

| 首次通过一道题 | +8 | 浇水（每次顶 10 分钟） | -8 |
| 再次通过 | +2 | 买种子 | -10 ~ -75 |

收获作物会返还更多能量（净赚 +8 ~ +90），所以「打卡 → 攒能量 → 种菜 → 收获」是个正循环。

### 收获之后的两条支线


## 三、配置苗小序（DeepSeek）

> ⚠️ 注意：CC Switch 里的 DeepSeek Key 是给 Claude Code 用的，**网站不会自动读取**。
> 需要把同一个 Key 再填一次到网站里（在网站「设置」页面）。

1. 打开 <https://platform.deepseek.com> → API Keys → 创建 Key（以 `sk-` 开头）
2. 登录网站 → 右上角「设置」→ 粘贴 Key → 保存
3. 回到 `/ai` 即可和苗小序对话；题目详情页也会出现「🌱 苗小序讲思路」「🌱 帮我看看哪错了」

Key 保存在 `config.json`（仅本机）。也可以设置环境变量 `DEEPSEEK_API_KEY` 代替。
没填 Key 时，AI 功能自动隐藏，其余功能不受影响。

## 五、怎么加新题目

编辑 `core/seed.py`，在 `PROBLEMS` 列表里追加一项：

```python
{
    "slug": "unique-id",              # 唯一标识
    "title": "题目标题",
    "category": "算法进阶",            # 六大板块之一
    "difficulty": "medium",            # easy / medium / hard
    "func": "my_func",                 # 要求实现的函数名
    "body": "题面描述\n支持换行",
    "starter": "def my_func(x):\n    pass\n",
    "tests": [
        {"args": [1], "expected": 2},
        {"args": [5], "expected": 10},
    ],
    "hint": "提示文字",
    "solution": "def my_func(x):\n    return x * 2\n",
},
```

保存后**重启服务**，题目会自动写入数据库（已存在的按 slug 更新）。

## 七、安全说明

判题沙箱做了四层限制：独立子进程、5 秒超时、白名单内置函数、禁用 import。
它适用于**本机 / 内网学习**。如果要部署到公网，请改用 Docker 容器或专业判题服务，
不要直接把本项目的判题接口暴露出去。
